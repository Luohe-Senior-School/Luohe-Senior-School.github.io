# 贡献指南

本页将会指导你如何对本网站进行贡献。

## 排版格式

> 本网站的排版格式参考了 [Minecraft 模组简体中文翻译指南](https://cfpa.site/TransRules) 的内容。

### 符号、数字、英文

本站所有页面全部要求使用 **简体中文** 进行编写，所有正文语句应当使用 **中文全角符号**，每句话结束后应当以问号、叹号、省略号或句号等句末标点符号结束，不得存在句末没有任何符号的语句。

对于数字和汉字之间 **不需要** 存在空格，如以下的表达均是符合格式规范的：

三角形有3条边。

对于英文与汉字之间 **需要** 存在空格，英文与数字之间的空格视情况而定：

联合国的英文缩写是 UN 。

汽车的位移是5km。
